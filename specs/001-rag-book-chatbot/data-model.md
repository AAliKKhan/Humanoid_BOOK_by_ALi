# Data Model for RAG Chatbot

This document defines the key data entities used in the RAG Chatbot feature.

## 1. Book Content

-   **Description**: Represents the raw text content from the book's source file (`app/book/page.tsx`). It is expected to be in Markdown format.
-   **Attributes**:
    -   `source_file`: (string) The path to the source file.
    -   `raw_text`: (string) The full text content of the book.

## 2. Text Chunk

-   **Description**: A smaller, semantically coherent segment of the `Book Content`. These chunks are the units that will be embedded and stored in the vector database.
-   **Attributes**:
    -   `chunk_id`: (string/UUID) A unique identifier for the chunk.
    -   `text`: (string) The text content of the chunk.
    -   `metadata`: (dict) A dictionary containing metadata about the chunk, such as its source, chapter, or page number. This will be used for filtering and providing context.
-   **Relationships**:
    -   Many-to-one relationship with `Book Content` (many chunks belong to one book).

## 3. Embedding

-   **Description**: A high-dimensional vector representation of a `Text Chunk` or a `User Query`. This is the core data structure used for similarity search.
-   **Attributes**:
    -   `vector`: (array of floats) The numerical vector generated by the Cohere embedding model.
-   **Relationships**:
    -   One-to-one relationship with a `Text Chunk` or `User Query`.

## 4. User Query

-   **Description**: The text question submitted by the user through the chatbot interface.
-   **Attributes**:
    -   `query_id`: (string/UUID) A unique identifier for the query.
    -   `text`: (string) The user's question.
    -   `timestamp`: (datetime) The time the query was submitted.

## 5. Chatbot Response

-   **Description**: The final answer generated by the Gemini model, which is sent back to the user.
-   **Attributes**:
    -   `response_id`: (string/UUID) A unique identifier for the response.
    -   `text`: (string) The generated answer.
    -   `retrieved_context`: (list of `Text Chunk`) The list of text chunks retrieved from Qdrant that were used to generate the response.
-   **Relationships**:
    -   One-to-one relationship with a `User Query`.
